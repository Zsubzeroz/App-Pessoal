Central Luan Estifer - Comandos Rápidos (Linux & Windows)

Para rodar em desenvolvimento:
npm run electron-dev

Para criar o executável (Build):
npm run electron-build

Para atualizar o código:
git pull origin master

Para desinstalar:
- No Linux:
  1. rm -rf ~/Dev/Projetos/App-Pessoal-master
  2. rm ~/.local/share/applications/central-luan.desktop
- No Windows:
  1. Delete a pasta do projeto.
  2. Delete o atalho criado na Área de Trabalho.
